# AI 能力招聘表达器

把“熟悉 AI 工具”这类笼统要求，转成具体工作任务、可观察证据、面试追问和人工复核节点。

## 在线预览

[打开 AI 能力招聘表达器](https://raw.githack.com/chenyuhuan555/recruiter-tools/main/projects/ai-capability-hiring-writer/index.html)

## 可以做什么

- 选择人才招聘、运营与内容、销售与客户或通用办公场景。
- 输入岗位日常任务，设置期望的独立程度与工作结果影响。
- 生成可编辑的 JD 表达建议、候选人能力证据和结构化面试追问。
- 对涉及候选人、客户或重要决策的任务，提示相应的人工复核节点。
- 一键复制生成的能力草案，便于继续编辑。
- 在当前浏览器页面内完成处理，不需要账号或后端服务。

## 使用方式

1. 打开 `index.html` 或在线预览。
2. 选择最接近岗位的工作场景。
3. 填写岗位名称和日常任务，并选择期望独立程度及结果影响。
4. 点击“生成岗位表达”，逐条检查并调整输出。
5. 由岗位负责人确认任务真实性，再将合适内容用于 JD 或面试提纲。

## 设计原则

- **从任务出发**：不以工具名称或模糊标签代替岗位能力。
- **证据可观察**：要求候选人说明做过什么、怎么核验结果。
- **人负责判断**：招聘工具辅助表达与追问，不自动给候选人打分或作出录用决定。
- **适度使用框架**：参考通用数智能力框架的任务化表达思路，不把页面输出包装成官方测评或证书。

人力资源和社会保障部职业技能鉴定中心发布的《通用数智能力框架》设有 6 个能力领域、22 个能力单元，文件明确其供结合实际参考使用，不具备强制性效力，也不作为职业技能等级认定依据。此项目是招聘表达演示，输出不是框架原文的完整复刻或官方评价结果。
