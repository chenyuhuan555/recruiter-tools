# AI+HR Signal Desk｜信号验证台

将 AI+HR 周报中的新闻拆成可核查的事实、有限边界内的推断，以及猎头可以采取的下一步动作。

## 预览

打开 `index.html` 即可使用。无需安装依赖或启动后端。

## 功能

- 按政策合规、需求端、工具端筛选本周信号
- 并列查看公开事实与基于事实的推断
- 展示关键数字、样本/分母、适用范围与信息新鲜度
- 为每条信息列出待核查项和猎头可执行动作
- 一键打开来源，并复制核查摘要

## 本期样例

- 北森 AI 收入披露：区分公司 AI 收入与招聘预算变化
- Mynavi 日本应届生调查：区分招聘计划与实际裁员
- 江苏失业缓冲期探索：区分政策探索与正式生效义务
- AI 面试调查：区分数据发布日期与媒体报道日期
- 惠誉就业分析：区分宏观总量与局部岗位变化

## 使用说明

本页面用于整理与讨论公开信息。信号强度是编辑判断的提示，不代表对信息真伪的自动判定，也不构成法律意见。引用数字时应回到原始报告核对样本、分母、调查时间和适用范围；遇到政策信息，应确认正式文件、发布机关和生效日期。
