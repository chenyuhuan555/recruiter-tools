# 猎头 HC 变化诊断器

客户提到 AI、预算或组织调整时，帮助猎头顾问快速澄清岗位需求状态，并整理下一步客户追问与寻访方向。

## 预览

打开 `index.html` 即可使用，无需安装依赖或启动后端。

## 功能

- 录入客户原话、岗位状态、AI 影响方式、HC 审批、工作变化、招聘时间和需求原因
- 归纳为新增扩编、离职替补、冻结暂缓、岗位取消、外包转移、AI 影响中的岗位重构或待澄清
- 输出适配的客户追问、寻访建议与风险提示
- 标记输入信息之间可能存在的矛盾
- 提供四种典型场景快速试用
- 分开记录“岗位没开出来”和“岗位换了画像”，也可同时勾选；分别生成 HC 卡点追问与新旧画像校准建议
- 一键复制追问清单

## 设计原则

工具把“AI 影响岗位”拆成任务变化与 HC 变化两个问题。自动化某些任务，并不必然代表岗位整体消失；外包规模收缩，也不必然转化为甲方新增编制。诊断结果用于沟通准备，最终状态需由客户确认。

## 文件结构

- `index.html`：单页交互工具，包含样例场景、诊断规则和页面样式
