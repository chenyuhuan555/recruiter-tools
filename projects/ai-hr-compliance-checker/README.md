# AI 招聘合规体检器

一个用于招聘文案初步自查的交互式页面。粘贴职位描述后，页面会标记可能需要复核的性别、婚育、年龄、民族宗教、户籍地域和外貌身体条件，并给出更贴近岗位职责的改写方向。

## 在线预览

[打开体检器](https://raw.githack.com/chenyuhuan555/recruiter-tools/main/projects/ai-hr-compliance-checker/index.html)

## 功能

- 展示命中词、所在上下文、提示原因和改写建议。
- 将规则分为高优先级提示与建议核实，便于人工复核。
- 提供示例职位描述，可直接体验检查流程。
- 所有文本在当前浏览器页面内处理，不会上传到服务端。
- 桌面端与移动端均可使用，无需安装依赖。

## 使用方式

1. 打开 `index.html`，或访问上方在线预览。
2. 粘贴职位描述，也可以点击“载入示例”。
3. 点击“开始体检”，逐条查看命中的原句和改写方向。
4. 结合岗位实际，由人事或法务人员完成复核。

## 检查范围与边界

页面使用预设关键词和规则进行提示，适合招聘文案的初步自查。关键词命中不代表违法；没有命中也不代表文案已通过合规审查。岗位性质、适用法规和具体事实都可能影响判断，因此结果不能代替法律意见、发布审批或招聘决策。

规则参考《中华人民共和国就业促进法》《中华人民共和国妇女权益保障法》及人力资源和社会保障部关于规范招聘信息、促进平等就业的相关通知。使用时应核对法规现行文本及具体适用情形。
