# 猎头顾问判断力案例库

一个围绕招聘判断设计的交互式案例练习。用户先查看 AI 初筛意见和候选人摘要，再展开关键线索，选择下一步动作，并阅读顾问复盘。

## 案例主题

- AI 产品经理：大厂与 AI 项目经历，能否证明独立推动 0 到 1？
- 区域业务负责人：长期任职代表稳定积累，还是可能存在动机风险？
- 公共事务经理：不同头衔和行业背景下，如何判断职责与能力迁移？

## 使用方式

直接打开 `index.html` 即可体验。选择左侧案例，阅读 AI 结论与职位摘要，展开材料线索后选择推荐、补充核验或暂不推荐，再查看顾问复盘。页面为单文件演示，无需安装依赖，选择过程仅在浏览器本地运行。

## 设计原则

- AI 结论作为讨论起点，不直接替代招聘决定。
- 关注候选人材料中可核验的事实、贡献范围和未知信息。
- 案例和候选人均为虚构，用于展示判断过程，不构成真实人才评价。
