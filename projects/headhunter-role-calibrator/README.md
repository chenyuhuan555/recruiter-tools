# 猎头岗位需求校准台

一张面向猎头项目启动阶段的岗位需求校准工作台。它将客户提供的招聘信息整理为业务目标、关键任务、必要条件、可培养条件和寻访前待确认问题，帮助顾问在开始搜寻前形成更清楚的岗位简报。

## 在线预览

[打开岗位需求校准台](https://raw.githack.com/chenyuhuan555/recruiter-tools/main/projects/headhunter-role-calibrator/index.html)

## 功能

- 记录招聘原因、工作地点与薪酬范围、入职 6–12 个月的预期交付。
- 拆分日常关键任务、必须具备能力和可培养 / 可替代条件。
- 记录客户对 AI 如何影响岗位任务的判断。
- 生成需求摘要、岗位画像草案、人才来源假设和客户待确认清单。
- 根据空缺字段提示项目启动前需要补问的信息。
- 支持复制简报和打印、保存为 PDF。
- 信息在当前浏览器本地处理，无需账号或后端服务。

## 使用方式

1. 填写客户或项目代称、岗位名称和招聘原因。
2. 描述预期交付及岗位最重要的日常任务。
3. 将能力拆分为到岗即用的必要条件，以及可培养或可替代条件。
4. 记录客户对 AI 影响的描述；不确定时保留待确认状态。
5. 生成简报，带着待确认问题与客户校准后再启动寻访。

## 设计边界

工具帮助猎头顾问澄清和记录客户需求，不替客户决定岗位是否应该设立、编制是否合理或候选人是否录用。客户确认岗位目标和录用标准；顾问据此整理人才画像、校准市场范围并开展寻访。结果是可编辑的工作草案，不是自动评估结论。
