# AI + HR Radar

一份关于 AI 招聘产品与招聘 Agent 的交互式观察报告。本期聚焦 Mira（Metix AI），梳理它如何把招聘需求推进到候选人触达与面试预约，并对照 LinkedIn、Workday、iCIMS 和 Workable 的产品方向。

## 页面内容

- **行业动态**：追踪近期 AI 招聘产品发布与行业整合
- **Mira 流程拆解**：查看需求澄清、人才寻访、匹配筛选、触达跟进和面试预约五个环节
- **人工复核模拟**：调整岗位方向和匹配分数，运行虚拟筛选并审批触达
- **产品能力对照**：比较不同产品的工作流位置、触达能力、面试排期和人工把关点
- **资料来源**：链接至产品方公告与公开研究资料

## 运行方式

无需安装依赖或配置 API。下载项目后，在浏览器中打开 `index.html` 即可使用。
