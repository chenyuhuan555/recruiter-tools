# 招聘 Agent 首版评测基线

本目录记录招聘简历评估 Agent 的首轮可复现实测。测试从 150 条脱敏合成金标中分层抽取 100 条，通过线上评估接口逐条运行，并统计准确率、幻觉率、人工接管率、时延和成本。

> 评测日期：2026-11-16  
> Agent：DeepSeek Flash / 招聘评估网站 v11  
> 数据版本：gold-v1.1-normalized

## 核心结果

| 指标 | 结果 | 结论 |
|---|---:|---|
| 通过判断准确率 | 83.0% | 受负样本占比影响，不能单独代表效果 |
| 正样本召回率 | 0.0% | 17 条应通过样本全部漏判，是当前最严重问题 |
| 硬性条件判断准确率 | 70.0% | 加分项、完整性与硬性条件存在混淆 |
| 评分平均绝对误差（MAE） | 29.46 | 分数明显偏低，最高分仅 86 |
| 可观测幻觉率 | 0.0% | 自动证据审计未发现无效引用或无依据元数据 |
| 证据引用准确率 | 100.0% | 连续原文逐字校验稳定 |
| 人工接管率 | 78.0% | 比金标接管率 38% 高 40 个百分点 |
| 人工接管判断准确率 | 56.0% | 42 条样本被不必要地转人工 |
| JSON 结构通过率 | 100.0% | 接口结构稳定 |
| 平均时延 | 2,504 ms | 性能可接受 |
| P95 时延 | 2,854 ms | 性能可接受 |
| 单次成本 | 约 ¥0.004617 | 按峰时、输入缓存未命中上限估算 |

## 最重要的产品结论

总体准确率 83% 容易造成误判。由于 100 条样本中只有 17 条金标通过样本，Agent 把所有人都判为不通过，也能获得 83% 的表面准确率。因此本版本应被视为**诊断基线**，不能作为上线验收结果。

## 主要失败类型与改进动作

| 优先级 | 失败类型 | 信号 | 改进动作 | 验收指标 |
|---|---|---|---|---|
| P0 | 正样本全部漏判 | 0/17 通过 | 增加正样本评分锚点；逐项输出硬性条件证据；满足关键条件后再判断待核实项 | 正样本召回率 ≥80% |
| P0 | 评分严重偏低 | MAE 29.46；最高分 86 | 固定五维权重与分数区间；加入 90 分以上示例；输出分项得分 | MAE ≤5 |
| P0 | 硬性条件误判 | 30/100 错误 | 先判断硬性要求，再汇总满足/不满足/待核实；加分项不得影响硬性状态 | 硬性准确率 ≥95% |
| P1 | 过度人工接管 | 接管率 78% | 仅关键硬性条件证据不足、矛盾、审计失败时接管 | 接管准确率 ≥90% |
| P1 | 金标输入契约不兼容 | 原始摘要均短于 200 字 | 重建完整合成简历；双人复核明显匹配和临界样本；记录金标版本与理由 | 100% 样本满足输入契约 |
| P2 | 证据与结构护栏需保持 | 引用、JSON 均 100% | 保留服务端逐字校验；增加人工语义抽检 | 人工抽检幻觉率 ≤1% |

## 文件说明

- `recruitment-agent-baseline-2026-11-16.xlsx`：适合作品集展示的完整评测报告。
- `baseline_100_inputs.json`：100 条分层抽样后的运行输入。
- `baseline_100_raw_results.json.gz`：线上接口原始返回、时延和 token 用量（无损 gzip 压缩）。
- `baseline_100_metrics.json`：逐样本判定、错误标签及聚合指标。
- `build_baseline_report.mjs`：从运行结果生成评测报告的脚本。

## 抽样与口径

100 条样本按场景分层抽取：明显匹配 17、明显不匹配 17、临界分 17、信息缺失 17、硬性冲突 16、异常输入 16。

- 通过判断：Agent 分数 ≥90、硬性要求满足、证据审计通过且完整性门槛达标。
- 可观测幻觉：证据引用不存在于原始简历，或当前公司/职位无法获得原文支持。
- 人工接管：Agent 输出 `insufficient`、硬性状态为“待核实”、证据审计失败或请求失败。
- P95 时延：服务端模型调用时延的最近秩法。
- 成本：按照 DeepSeek Flash 峰时、输入缓存未命中价格估算。

## 限制

1. 原始 150 条金标是合成简历摘要，长度均低于网站的 200 字完整简历门槛。本次运行仅追加统一的脱敏与缺失信息说明，没有新增候选人事实；原始 v1.0 保持不变。
2. “幻觉率 0%”是自动化护栏口径，不等同于独立人工语义审计。
3. 金标中的明显匹配与临界样本仍需双人复核，确认评分和硬性状态的一致性。
