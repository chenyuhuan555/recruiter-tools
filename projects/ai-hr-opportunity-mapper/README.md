# AI+HR 场景机会评估器

一个用于梳理 HR 工作流、比较 AI 试点机会的交互式演示页。用户可以选择组织类型和业务场景，输入处理量、单次耗时、数据准备度与流程重复度，查看机会排序、工时估算及试点建议。

## 功能

- 覆盖人力资源服务公司、企业 HR 团队和猎头招聘团队的常见场景。
- 按处理规模、重复程度、数据准备情况和场景风险生成可解释的排序。
- 展示月度工时与工时价值参考，并提供分阶段试点路线。
- 标出人工复核和人工决策的边界。
- 单文件运行，无需安装依赖；计算在浏览器本地完成。

## 使用

直接打开 `index.html`，修改左侧参数或切换组织类型即可更新结果。页面中的默认数据仅用于演示。估算不包含软件、集成和治理成本，不代表实际收益承诺；正式决策前应使用代表性样本进行试点验证。

## 人工决策边界

工具用于发现流程自动化机会，不用于自动拒绝候选人、决定录用、确定薪酬或判断员工权益。涉及候选人匹配、外部联系和异常解释的结果需要人工复核。
