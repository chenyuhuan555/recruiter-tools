# 第一版范围与验收

已确认目标：场景评估、输入岗位生成寻访方向及公开来源的小原型、实测复盘。

1. 保存目录和实测证据。验收：每次数据调用有 call_id、状态、价格；人物样本只保留统计。
2. Python 标准库本地网页：填写岗位/行业/城市/技能，生成三组检索；示例回放绑定明确案例；实时模式经服务端访问 treg。验收：无凭证可用回放，有凭证可查询；失败明确展示。
3. 报告写明适用性、费用口径、样本局限、失败案例、人工核实内容。验收：不虚构时间节省或候选人匹配率。
4. 检查请求校验、来源链接、导出和启动；打包供 GitHub 发布审阅。

取舍：固定规则容易解释、无需额外模型费用；复杂 JD 理解留给人工填写字段。首版不是全自动候选人推荐系统。只监听本机；密钥读取服务端环境变量；实时每次一条查询，上限 $0.01，无自动重试。示例回放不花钱。
