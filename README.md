# 🎯 猎头AI指令工程工作台

将「岗位需求 → AI搜索指令 → 倍罗搜索」这个链路产品化的工具包。

---

## 📦 包含什么

| 文件 | 作用 |
|------|------|
| `prompt-template.md` | Claude 提示词模板 — 粘入 JD，生成 4 种搜索指令变体 |
| `prompt-library.html` | 指令库网页应用 — 保存/搜索/复用指令，支持 GitHub 云同步 |
| `README.md` | 本文件 — 使用指南 |

---

## 🚀 快速开始（5 分钟）

### 第一步：准备 GitHub 仓库

1. 在 GitHub 上创建一个**私有仓库**（如 `recruiter-prompts`）
2. 在仓库 Settings 中创建 `prompts.json` 文件（内容为 `[]`）
   - 或者直接让工具自动创建（首次保存时会自动生成）

### 第二步：创建 GitHub Token

1. 打开 https://github.com/settings/tokens
2. 点击 **「Generate new token」→「Generate new token (classic)」**
3. 填写 Note（备注）：`猎头指令库`
4. 勾选权限：**`repo`**（如果要存私有仓库）或 **`public_repo`**（公开仓库）
5. 点击底部 **「Generate token」**
6. ⚠️ **复制生成的 Token**（格式为 `ghp_xxxxxxxxxxxx`），关闭页面后将无法再次查看

### 第三步：启动指令库

1. 双击打开 `prompt-library.html`
2. 在欢迎页面填写：
   - **GitHub Token**：刚才复制的 Token
   - **仓库所有者**：你的 GitHub 用户名
   - **仓库名**：第一步创建的仓库名（如 `recruiter-prompts`）
   - **JSON 文件路径**：默认 `prompts.json`
   - **你的名字**：用于标记谁创建/修改了指令
3. 点击 **「开始使用」**
4. 看到「已同步」即表示配置成功 ✅

## 📖 日常使用流程

```
① 收到客户 JD（职位描述）
      │
      ▼
② 在 Claude Code 中输入：
   "请根据 prompt-template.md 中的模板，把以下 JD 生成 4 个搜索变体：
   [粘贴 JD]"
      │
      ▼
③ Claude 生成 A/B/C/D 四个变体，每个都包含：
   - 🔍 可直接复制的搜索查询语句
   - 📝 查询策略说明
   - 💡 使用建议
      │
      ▼
④ 把每个变体分别复制到倍罗 AI (belloai.com) 搜索
      │
      ▼
⑤ 把效果好的搜索指令保存到 prompt-library.html：
   - 点击「➕ 添加指令」
   - 填写标题、标签、粘贴搜索语句
   - 选择变体类型和来源模型
   - 在备注中记录使用心得
      │
      ▼
⑥ 下次遇到类似岗位：
   - 打开 prompt-library.html
   - 搜索关键词（如"Java 金融"）
   - 筛选变体类型或模型
   - 点击「📋 复制」→ 粘贴到倍罗
```

## 👥 团队协作

1. 每个团队成员在自己的电脑上打开 `prompt-library.html`
2. 配置**同一个 GitHub 仓库**的信息
3. 各自使用自己的 GitHub Token（每人创建一个 Token）
4. 数据自动同步：
   - 打开页面时自动拉取最新指令
   - 保存/编辑/删除后自动推送到云端
   - 点击「🔄 同步」按钮手动拉取他人的更新
5. 如果两人同时修改，后保存的人会看到冲突提示，点击同步获取最新数据后再操作

## ❓ 常见问题

### Q: Token 安全吗？
A: Token 保存在浏览器 localStorage 中，不会上传到任何第三方服务器。建议使用细粒度 Token，仅授予单个仓库的读写权限。Token 可随时在 GitHub 设置中吊销。

### Q: 离线能用吗？
A: 有网络时数据始终同步到 GitHub。离线时无法拉取/推送，但上次加载的数据仍可浏览和复制。恢复网络后点击同步按钮即可。

### Q: 为什么选择 GitHub 而不是数据库？
A: GitHub 免费、自带版本历史（每条修改都是 Git commit）、无需服务器、无需维护。团队天然可用。

### Q: 指令库数据太多怎么办？
A: 使用搜索和筛选功能快速定位。标签系统可以帮助分类管理。如果数据量极大（数千条），GitHub API 仍可正常处理。

### Q: 如何生成搜索指令？
A: 使用 Claude Code（你现在在用的工具），对 Claude 说：「请根据 D:\New project\prompt-template.md 生成搜索指令」，然后粘贴岗位需求。
